Guitar Pro 파일을 여는 macOS용 악보 뷰어입니다. 표준 악보와 TAB을 함께 보여 주고, 반복 기호까지 그대로 재생하며, 느리게·반복해서 연습하고, 직접 고쳐 PDF로 뽑을 수 있습니다. 소리는 macOS 내장 음원이나 내 Mac의 Audio Unit·VST® 3 가상악기로 냅니다.

Features

악보 하나로 연습의 처음부터 끝까지

Guitar Pro 3부터 8까지의 파일을 그대로 열고, 별도 설치 없이 macOS 내장 음원으로 바로 재생하고, 원하면 Mac에 설치된 Audio Unit·VST 3 악기로도 들을 수 있습니다.

표준 악보 + TAB

표준 악보와 TAB을 함께, 또는 TAB만·표준 악보만 골라 봅니다. 드럼 악보도 지원하고 확대·축소가 자유롭습니다.

  • 코드 이름, 섹션 마커, 셋잇단음표 표시
  • 벤딩·슬라이드·하모닉스 등 기타 주법 기호

반복까지 그대로 재생

도돌이표, 다른 결말(1., 2.), 곡 중간의 템포 변화를 악보대로 펼쳐 재생합니다. 소리는 macOS 내장 General MIDI 사운드뱅크나, 설치된 Audio Unit·VST 3 악기 중에서 고릅니다.

연습 도구

재생 속도 25%~200%, 메트로놈, 반복 재생. 재생 커서를 따라 악보가 자동으로 넘어가고, 마디를 클릭하면 그 자리부터 다시 듣습니다.

트랙 믹서 & 지판 뷰

트랙마다 음소거·솔로·볼륨을 조절해 내 파트만 빼고 반주에 맞춰 칠 수 있습니다. 지판 뷰는 지금 울리는 음의 위치를 보여 줍니다.

악보 작성 · 편집

기타·베이스·7현·우쿨렐레·드럼으로 새 악보를 시작하고, 숫자 키로 프렛을 입력하는 키보드 중심 편집기로 빠르게 씁니다. 저장은 Guitar Pro 5(.gp5) 형식입니다.

PDF 저장 · 인쇄

현재 트랙이나 모든 트랙을 PDF로 저장하거나 바로 인쇄합니다. A4 등 용지 크기에 맞춰 페이지를 나누고, 제목 머리말과 쪽 번호를 넣습니다.

외부 가상악기 (Audio Unit · VST 3)

음원 메뉴에서 설치된 Audio Unit(AUv2/AUv3)이나 VST 3 악기를 고르면 플러그인 창이 열리고, 고른 프리셋 음색으로 악보가 재생됩니다. 음색은 저장되어 다음에도 그대로 쓰입니다.

  • 드럼 트랙은 내장 GM 음원으로 유지(선택)
  • 멀티팀브럴: 트랙마다 다른 MIDI 채널과 악기·팬 전송
  • 악보를 직접 연주하는 플러그인(Tablarion 등)과 악보 동기화

곡 구조 편집

트랙을 추가·삭제하고 이름·악기·GM 음색·튜닝·카포를 바꿉니다. 마디마다 박자표·조표, 도돌이표와 반복 횟수, 다른 결말(1., 2.), 섹션 이름을 정하고, 곡 정보(제목·아티스트·작곡·템포 등)를 채웁니다.

Install

설치하기

Apple 공증(Notarization)을 받지 않은 개인 배포 앱이라, 처음 한 번은 macOS의 보안 확인을 직접 통과시켜야 합니다.

내려받아 응용 프로그램 폴더로 옮기기

Releases 페이지에서 TabViewer.app.zip을 받아 압축을 풀고, TabViewer.app을 응용 프로그램 폴더로 드래그합니다.

처음 실행 허용하기

처음 열면 macOS가 보안 경고를 띄웁니다. 휴지통으로 이동은 누르지 말고 완료(macOS 14에서는 취소)로 창을 닫으세요. 그다음 시스템 설정 › 개인정보 보호 및 보안 아래쪽의 그래도 열기를 클릭하고 암호를 입력하면 됩니다.

터미널이 편하다면 아래 명령 한 줄로도 됩니다.

xattr -dr com.apple.quarantine /Applications/TabViewer.app

악보 열기

Guitar Pro 파일을 Dock의 TabViewer 아이콘 위로 끌어다 놓거나, 파일 › 열기(⌘O)로 엽니다. 새 악보는 파일 › 신규(⌘N)에서 시작합니다.

(선택) 더블클릭으로 열리게 하기

파일을 선택하고 ⌘I(정보 가져오기) › 다음으로 열기에서 TabViewer를 고른 뒤 모두 변경…을 누르면, 같은 확장자의 파일이 모두 TabViewer로 열립니다.

앱 화면은 한국어입니다. 메뉴와 버튼은 한국어로 표시되며, 단축키는 위 표와 같습니다.

FAQ

자주 묻는 질문

Guitar Pro에서 듣던 소리와 다르게 들려요.

TabViewer는 Guitar Pro의 RSE(Realistic Sound Engine) 사운드 대신 macOS에 내장된 General MIDI 음색으로 재생합니다. 음과 리듬, 반복 구조는 악보 그대로지만 음색은 다를 수 있습니다. 더 실제에 가까운 소리를 원하면 음원 메뉴에서 설치된 Audio Unit·VST 3 악기를 고르세요.

편집하려고 하면 왜 새 창에 사본이 생기나요?

다른 프로그램에서 만든 파일에는 TabViewer가 읽지 못하는 정보(사운드 설정, 가사 등)가 들어 있을 수 있습니다. 이를 지우지 않도록 원본은 그대로 두고 사본을 편집합니다. 사본은 .gp5로 저장되며, TabViewer로 저장한 파일은 바로 편집할 수 있습니다.

.gp(Guitar Pro 7/8) 형식으로 저장할 수 있나요?

현재는 Guitar Pro 5(.gp5) 형식으로만 저장합니다. GP5 형식을 읽는 다른 악보 프로그램에서도 열 수 있도록 표준 구조로 저장합니다.

Guitar Pro가 없어도 되나요?

네. TabViewer는 독립 프로그램이라 Guitar Pro 없이 파일을 열고 재생하고 편집할 수 있습니다. 기본 재생에는 별도 사운드뱅크나 플러그인이 필요 없습니다.

인터넷에 연결하거나 정보를 보내나요?

TabViewer 자체는 인터넷에 연결하지 않으며, 파일은 내 Mac 안에서만 열고 저장합니다. 개인정보를 수집하지 않습니다. 다만 직접 불러온 서드파티 플러그인은 라이선스 인증 등을 위해 스스로 연결할 수 있으며, 이는 각 제조사의 정책을 따릅니다. 악보 동기화를 켜면 열린 악보가 선택한 플러그인에 전달됩니다.

갖고 있는 가상악기로 재생하려면 어떻게 하나요?

메뉴 막대의 음원 메뉴에서 악기를 고르면 플러그인 창이 열립니다. 여기서 프리셋을 고르고 창을 닫으면 그 음색이 저장되어 재생에 쓰이고, 상태 표시줄 오른쪽에 음원 이름이 보입니다(다시 열기: ⌥⌘I). 일반 멀티팀브럴 플러그인은 파트마다 수신 채널을 1, 2, 3…으로 맞추세요. 새로 설치한 악기가 안 보이면 플러그인 다시 검색을 누르세요. iLok으로 보호되는 플러그인은 iLok License Manager가 설치·인증되어 있어야 합니다.

VST 2 플러그인도 쓸 수 있나요?

아니요. VST 3(.vst3)와 Audio Unit 형식만 지원합니다. 대부분의 상용 가상악기는 설치할 때 VST 3나 Audio Unit 버전을 함께 설치할 수 있습니다.

Tablarion처럼 악보를 직접 연주하는 플러그인과 쓸 수 있나요?

네. Tablarion은 TabViewer와 같은 저작자가 무료로 배포하는 플러그인입니다(별도 설치). 음원 › 악보 재생 플러그인과 동기화(기본 켜짐)를 켜 두면, MIDI 음표 대신 열린 악보를 플러그인에 넘기고 TabViewer의 재생 위치·템포를 따르게 합니다. 줄·주법·트랙별 악기가 그대로 쓰여 플러그인에서 직접 재생할 때와 같은 소리가 나며, 상태 표시줄에 "악보 동기화"가 표시됩니다. 트랙 볼륨·음소거·솔로는 재생을 시작할 때 반영됩니다.

외부 악기를 골랐는데 소리가 안 나요.

상태 표시줄의 음원 이름이 고른 플러그인인지 확인하세요(오류 창이 떴다면 불러오지 못한 것입니다). 플러그인 창에서 음색이 선택되어 있는지, 플러그인 볼륨이 0이 아닌지 확인하세요. 트랙 1만 들리면 플러그인 파트의 MIDI 채널을, 단일 음색 플러그인이면 트랙마다 다른 MIDI 채널 사용을 끄세요. 드럼이 이상하면 드럼 트랙은 내부 음원으로 재생을 켭니다.

다른 악보를 열면 이전 창이 닫혀요.

파일을 열면 기존 악보 창을 새 악보로 대체합니다. 수정한 악보는 닫기 전에 저장할지 묻고, 취소하면 그 창은 남습니다. 여러 파일을 한 번에 고르면 모두 함께 열립니다.
